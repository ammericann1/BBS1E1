📋 WHAT YOU NEED TO FILL IN YOUR .ENV FILE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

┌─ 1️⃣  GOOGLE DRIVE (Your Source Video) ──────────────────────────────────┐
│                                                                          │
│  GOOGLE_DRIVE_FILE_ID=_____________________________                     │
│    ↑ Get from: Drive URL between /d/ and /view                         │
│    Example: https://drive.google.com/file/d/1AbC-DeF/view              │
│    Copy: 1AbC-DeF                                                       │
│                                                                          │
│  GOOGLE_APPLICATION_CREDENTIALS=credentials.json                        │
│    ↑ Download from: console.cloud.google.com                           │
│    → Create Service Account → Download JSON key                         │
│    → Save as credentials.json in project folder                         │
│    → SHARE your Drive video with service account email!                │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

┌─ 2️⃣  CLOUDINARY (Video Hosting) ────────────────────────────────────────┐
│                                                                          │
│  CLOUDINARY_CLOUD_NAME=_____________________________                    │
│  CLOUDINARY_API_KEY=_____________________________                       │
│  CLOUDINARY_API_SECRET=_____________________________                    │
│    ↑ Get from: cloudinary.com/users/register/free                      │
│    All 3 values shown on dashboard after signup                         │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

┌─ 3️⃣  INSTAGRAM (Publishing) ─────────────────────────────────────────────┐
│                                                                          │
│  INSTAGRAM_USER_ID=_____________________________                        │
│    ↑ Get from: developers.facebook.com (Graph API Explorer)            │
│    1. GET me/accounts (copy page ID)                                    │
│    2. GET PAGE_ID?fields=instagram_business_account                     │
│    3. Copy the instagram_business_account id                            │
│                                                                          │
│  INSTAGRAM_ACCESS_TOKEN=____________________________________________    │
│    ↑ Get from: developers.facebook.com/tools/accesstoken/              │
│    Generate token → Extend Access Token → Copy long token              │
│    (This expires every 60 days - you'll need to refresh it)            │
│                                                                          │
│  INSTAGRAM_API_VERSION=v21.0  ← Leave as-is                            │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

🧪 TEST COMMANDS (Run in order)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. python -m app.main validate-config
     → Checks all credentials are valid

  2. python -m app.main download
     → Downloads video from Google Drive (10-20 min)

  3. python -m app.main inspect-source
     → Shows video details and audio tracks

  4. python -m app.main process
     → Generates all clips (1-2 hours)

  5. python -m app.main status
     → Shows progress and clip counts
